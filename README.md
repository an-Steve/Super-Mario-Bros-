# ✨ Fonctionnalités

## 🎮 Gameplay
- Déplacements fluides
- Système de saut réaliste avec gravité
- Caméra dynamique suivant Mario
- Système de vies ❤️
- Niveaux infinis avec difficulté progressive

---

## 👾 Ennemis & Boss

### Ennemis
- 🍄 Goombas
- 🐢 Koopas
- 🍄 Champignons sauteurs

### Boss Final
- 🐲 Bowser volant
- Barre de vie dynamique
- Boules de feu
- Combat disponible à partir du niveau 3

| Objet | Effet |

Le système météo change automatiquement pendant la partie :

- 🌧️ Pluie
- ⛈️ Orage
- ❄️ Neige
